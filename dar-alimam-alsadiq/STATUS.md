# أين وصل مشروع «دار الإمام الصادق»

آخر تحديث: 2026-11-06

## الخلاصة

المشروع في **مرحلة القرارات**، ولم تبدأ البرمجة بعد. اكتملت التعليمات الثابتة، وبدأ حسم بنود المنصة ولم يُجب منها شيء.

## ما أُنجز

- [x] اعتماد الاسم «دار الإمام الصادق» والنطاق (طلاب الحوزة عامة).
- [x] جمع تصور محمد وتصور الزميل، وحسم التعارضات الثلاثة (النطاق، والمرحلة، ومعيار المعلومة).
- [x] النص النهائي للتعليمات الثابتة: [custom-instructions.md](custom-instructions.md)
- [x] إنشاء المستودع وترخيصه AGPL-3.0.
- [x] نقل مخرجات المشروع إلى هذا المجلد في المستودع.

## ما بقي

- [ ] جعل المستودع خاصا (يتم من إعدادات GitHub، انظر التنبيه أدناه).
- [ ] حسم البنود الأحد عشر المفتوحة في [decisions.md](decisions.md)، بدءا بوحدة الإطلاق الأول.
- [ ] تفصيل البنود الخاصة (الوحدات، والأدوار، والكشكول، والتوثيق، وكتب العلوم، والمشاريع الفرعية).
- [ ] دمج قرارات محمد مع قرارات الزميل في مشروع واحد.
- [ ] كتابة مواصفة لكل ميزة («المهارة قبل الميزة»)، ثم بدء البرمجة.
- [ ] نقل ما يصلح من «دار الصادق» القديمة قسما بعد قسم، ثم حذفها.

## تنبيه عن جعل المستودع خاصا

هذا المستودع يضم أيضا تطبيقات أخرى (مرشد النسك، وحاسبة المواريث، والمعالم الناضرة، والمسبار). وصفحة الخصوصية التي يشير إليها متجر Google Play
(`https://taroot80-blip.github.io/Dar-alemaam-alsadig/privacy.html`) تُنشر من هذا المستودع عبر GitHub Pages.
في الحساب المجاني تتوقف GitHub Pages إذا صار المستودع خاصا، فيتعطل ذلك الرابط.
