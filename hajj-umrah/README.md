# مرشد النسك — أحكام الحج والعمرة (المذهب الجعفري)

تطبيق ويب تفاعلي (PWA) يعمل دون إنترنت، يُغلَّف لاحقاً تطبيقَ أندرويد (AAB)، موجّه لمرشدي الحج والعمرة.

- **المحتوى:** مشجرات «الحدائق الناضرة» — إعداد حسين الجزيري (العمرة المفردة، محرمات الإحرام، أعمال العمرة).
- **التصميم:** محمد علي المعاتيق.

## البنية
| المسار | الوصف |
|---|---|
| `index.html` | الواجهة كاملة (الرحلة، المسائل، شجرة الفتوى، البحث، المراجع، العدّادات، الخرائط) |
| `data/journey.js` | محطات رحلة النسك ومساراها (العمرة المفردة / حج التمتع) — يدوي |
| `data/issues.js` | المسائل المستخرجة آلياً من فهارس الملفات — **مولَّد** |
| `data/text.js` | نص الشرائح للبحث — **مولَّد** |
| `data/rulings.js` | شجرة الفتوى: تفريغ أقوال المراجع شريحةً شريحة — يدوي |
| `data/overrides.js` | تصحيح العناوين ونقل المسائل وأسماء المراجع الكاملة — يدوي |
| `slides/<الكتاب>/NNN.webp` | الشرائح الأصلية (و`.t.webp` مصغّرات) |
| `tools/` | سكربتات الاستخراج |

## إضافة ملف جديد (مثلاً أحكام الحج)
1. ضع ملف PDF في مجلد المصادر باسم قصير (`hajj_tamattu.pdf`).
2. أضفه إلى `BOOKS` و`TOC_PAGES` في `tools/build_data.py`.
3. حوّل الشرائح: `pdftoppm -r 130 -png <ملف> png/<الاسم>` ثم إلى webp (انظر المهارة).
4. شغّل `python3 -I tools/build_data.py <مجلد المصادر>`.
5. اربط وسوم المسائل بمحطات الحج في `data/journey.js` (حقل `topics`) وأزل `pending`.

## التشغيل محلياً
`python3 -m http.server` ثم افتح `http://localhost:8000`.
